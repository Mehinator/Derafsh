## فارسی

### دانلود و اجرا (ویندوز)

1. از بخش [Releases](https://github.com/Mehinator/Derafsh/releases/latest) فایل `Derafsh-v…-Windows-x64.zip` را دانلود کنید.
2. فایل را از حالت فشرده خارج کنید و `Derafsh.Client.exe` را اجرا کنید. نصب لازم نیست.
3. اگر ویندوز پیام «Windows protected your PC» داد: روی **More info** و بعد **Run anyway** بزنید (برنامه امضای دیجیتال ندارد).

نیازمندی: ویندوز ۱۰ (نسخه ۱۸۰۹ به بعد) یا ویندوز ۱۱، ۶۴ بیتی.

### طرز استفاده

برنامه دو صفحه دارد:

**صفحه‌ی اصلی** فقط یک دکمه‌ی گرد **اتصال** دارد. درفش خودش سرورها را روی **همان اینترنتی که الان وصل هستید** تست می‌کند و به سریع‌ترین سروری که جواب بدهد وصل می‌شود. اگر تیک **«فقط سرورهایی که Gemini (هوش مصنوعی گوگل) را باز می‌کنند»** را بزنید، هم سروری که وصل می‌شوید و هم سرورهای زاپاس همه Gemini را باز می‌کنند.

**برنامه‌ها و سایت‌های ایرانی بدون VPN** (تیک دوم، پیش‌فرض روشن): سایت‌های ایرانی (دامنه‌ی ‎.ir‎، چند سایت پرکاربرد مثل دیجی‌کالا و آپارات، و IPهای ایران) با اینترنت خود دستگاه باز می‌شوند؛ بانک‌ها و درگاه پرداخت فقط IP ایران را قبول می‌کنند. در اندروید، برنامه‌های ایرانی و بانکی هم خودکار بدون VPN می‌مانند.

**انتخاب برنامه‌ها** (اندروید، کنار همان تیک): خودتان انتخاب کنید کدام برنامه‌ها از VPN استفاده کنند. دو حالت دارد: «همه‌ی برنامه‌ها با VPN، جز آن‌هایی که خاموش کنید» یا «فقط برنامه‌هایی که روشن کنید با VPN». تغییرها همان لحظه اعمال می‌شوند.

**صفحه‌ی سرورها** (دکمه‌ی «سرورها» بالای صفحه) برای کارهای بیشتر است. از منوی **لیست** یکی را انتخاب کنید:

| لیست | چه چیزی نشان می‌دهد | دکمه‌ها |
|---|---|---|
| **آنلاین** | سرورهای رایگانی که روی همین اینترنت جواب می‌دهند، سریع‌ترین بالا | **تست دوباره** · **دریافت لیست تازه** · **ذخیره به‌عنوان لیست** |
| **شخصی** | کانفیگ‌هایی که خودتان اضافه کرده‌اید | **تست دوباره** · **افزودن کانفیگ** · **ذخیره به‌عنوان لیست** |
| **لیست‌های ذخیره‌شده** | هر لیستی که با اسم دلخواه ذخیره کرده‌اید، مثلاً «ایرانسل» یا «وای‌فای خانه» | **تست دوباره** · **حذف این لیست** |

روی هر سرور بزنید تا برای اتصال انتخاب شود (در صفحه‌ی اصلی، **خودکار** دوباره انتخاب را به برنامه می‌سپارد). دکمه‌های هر سرور: **پینگ** (سرعت)، **Gemini** (آیا Gemini باز می‌شود)، **اشتراک** (فرستادن لینک کانفیگ برای دیگران)، **✧** (علاقه‌مندی) و **+ شخصی** (افزودن به لیست شخصی). زیر هر سرور آدرس آن و کانال تلگرامی که از آن آمده نوشته شده است.

با دکمه‌ی **«اشتراک سالم‌ها»** در صفحه‌ی سرورها، لینک همه‌ی سرورهایی که الان جواب می‌دهند یکجا برای دیگران فرستاده می‌شود.

**وصل ماندن:** کانفیگ‌های رایگان زود قطع یا کند می‌شوند. تا وقتی وصل هستید، درفش دو سرور سالم دیگر را به‌عنوان **زاپاس** آماده نگه می‌دارد (هر ۴ دقیقه دوباره تست می‌شوند) و هر ۱۰ ثانیه اتصال را از داخل خودش امتحان می‌کند. اگر سرور جواب ندهد، یا **کند شود** (مثلاً ویدیو وسط پخش بایستد: سرعت دو بار پشت سر هم زیر ۲۰ کیلوبایت بر ثانیه و زاپاس سریع‌تر باشد)، خودکار به زاپاس می‌رود و وصل می‌مانید؛ در اندروید VPN روشن می‌ماند، حتی وقتی برنامه بسته است. هر وقت خودتان خواستید، دکمه‌ی **«تعویض سرور»** زیر اسم زاپاس همین الان به آن می‌رود. موقع وصل شدن هم اتصال واقعاً امتحان می‌شود و اگر سروری فقط «وصل» شود ولی اینترنت ندهد، سرور بعدی امتحان می‌شود.

**سرعت، نه فقط پینگ:** پینگ خوب یعنی سرور جواب می‌دهد، نه اینکه ویدیو را روان پخش کند. درفش سرعت دانلود هر سرور را هم اندازه می‌گیرد (کنار هر سرور، مثلاً «۲۴۰ KB/s») و سرورهایی را که برای ویدیو سریع‌اند (۱۵۰ KB/s به بالا) اول انتخاب می‌کند. سروری که فقط به پینگ جواب می‌دهد ولی چیزی دانلود نمی‌کند (در تست، نصف سرورهای پینگ‌دار) سالم حساب نمی‌شود. QUIC (UDP 443) بسته می‌شود تا اینستاگرام و یوتیوب از راه پایدارتر TCP بروند؛ روی سرورهای رایگان QUIC معمولاً همان چیزی است که ویدیو را وسط پخش نگه می‌دارد.

**حافظه‌ی هر اینترنت:** درفش به خاطر می‌سپارد کدام سرورها روی همین اینترنت (ایرانسل، همراه اول، وای‌فای خانه و …) جواب داده‌اند و کدام نه، و دفعه‌ی بعد اول همان‌ها را تست می‌کند. برای همین تست بعدی خیلی سریع‌تر جواب می‌دهد. این اطلاعات فقط روی همین دستگاه می‌ماند.

**تست دقیق:** هر سرور بعد از باز شدن تونل، سه بار دیگر با HTTPS امتحان می‌شود و فقط وقتی «سالم» حساب می‌شود که دست‌کم دو بار جواب بدهد (پینگ = میانه). تست Gemini کشوری را می‌خواند که گوگل شما را در آن می‌بیند؛ بعضی سرورهای رایگان IP خارجی دارند ولی ترافیک گوگل را از ایران رد می‌کنند و Gemini با آن‌ها باز نمی‌شود — این‌ها «Gemini ✗ · IRN» نشان داده می‌شوند.

**نسخه‌ی تازه:** وقتی نسخه‌ی جدیدی روی گیت‌هاب بیاید، بالای برنامه خبر داده می‌شود و دکمه‌ی **دانلود** فایل مخصوص همان دستگاه را می‌گیرد.

در ویندوز، درفش موقع اتصال پروکسی سیستم را روی خودش می‌گذارد و موقع قطع، تنظیم قبلی شما را برمی‌گرداند.

موتور Xray نیز فورک [patterniha/Xray-core](https://github.com/patterniha/Xray-core) است (همان که پترن استفاده می‌کند): اتصال به کانفیگ‌های VLESS/Trojan بدون رمزنگاری روی آدرس‌های عمومی کار می‌کند و پارامترهای `cs=` (cipherSuites) و `alpn` لینک‌ها با قانون http/1.1 برای ws اعمال می‌شوند — همان روشی که تست‌ها را در پترن درست نشان می‌دهد.

### اندروید

1. از بخش [Releases](https://github.com/Mehinator/Derafsh/releases/latest) یکی از این فایل‌ها را روی گوشی دانلود کنید:
   - `Derafsh-v…-Android-arm64.apk`: بیشتر گوشی‌های چند سال اخیر
   - `Derafsh-v…-Android-armv7.apk`: گوشی‌های قدیمی‌تر و ارزان‌تر (۳۲ بیتی). اگر arm64 نصب نشد، این را بگیرید
   - `Derafsh-v…-Android-universal.apk`: اگر نمی‌دانید کدام؛ روی همه کار می‌کند ولی حجمش بیشتر است
2. فایل را باز کنید. اگر اندروید اجازه‌ی «نصب برنامه‌های ناشناس» خواست، برای همان مرورگر یا فایل‌منیجر اجازه بدهید و **Install** را بزنید.
3. در درفش یک کانفیگ را انتخاب کنید و **Connect** را بزنید. بار اول اندروید می‌پرسد که درفش اجازه‌ی ساختن VPN دارد یا نه: **OK** را بزنید.

نیازمندی: اندروید ۶ به بعد.

اگر می‌خواهید از برنامه‌ی دیگری استفاده کنید، همین لیست را می‌توانید در **v2rayNG**، **Hiddify** یا **NekoBox** هم اضافه کنید؛ هر ۲ ساعت خودکار به‌روز می‌شود:

1. در برنامه به بخش **Subscription group setting** (تنظیمات اشتراک) بروید و **+** را بزنید.
2. این آدرس را وارد کنید:
   ```
   https://cdn.jsdelivr.net/gh/Mehinator/Derafsh@main/derafsh_sub.txt
   ```
3. **Update subscription** را بزنید، کانفیگ‌ها را تست کنید و به یکی از سریع‌ها وصل شوید.

### آیفون و آیپد

درفش هنوز نسخه‌ی iOS ندارد، ولی همین لیست کانفیگ‌ها روی آیفون و آیپد هم کار می‌کند:

1. یکی از این برنامه‌های رایگان را از App Store نصب کنید: **Hiddify**، **V2Box** یا **Streisand**. (App Store رسماً در ایران فعال نیست؛ این برنامه‌ها در App Store کشورهای دیگر هستند.)
2. در برنامه، افزودن اشتراک (**Subscription** یا **+**) را بزنید و این آدرس را وارد کنید، یا QR زیر را با همان برنامه اسکن کنید:
   ```
   https://cdn.jsdelivr.net/gh/Mehinator/Derafsh@main/derafsh_sub.txt
   ```
   <img src="docs/sub-qr.png" width="180" alt="QR لینک اشتراک درفش">
3. لیست را به‌روز کنید، سرورها را تست کنید (**Ping** یا **Test**) و به یکی از سریع‌ها وصل شوید. لیست هر ۲ ساعت خودکار تازه می‌شود.

این برنامه‌ها مثل درفش سرورها را روی اینترنت خود شما نمی‌سنجند، پس بعضی از سرورهای لیست جواب نمی‌دهند؛ اول تست کنید و یکی از سالم‌ها را انتخاب کنید.

### کانفیگ‌ها از کجا می‌آیند؟

اسکریپت [`collector.py`](collector.py) هر ۲ ساعت روی GitHub Actions اجرا می‌شود:

1. صفحه‌ی عمومی چند کانال تلگرام و چند لیست عمومی گیت‌هاب را می‌خواند (فهرست در همان فایل؛ از جمله [SoliSpirit](https://github.com/SoliSpirit/v2ray-configs)، [barry-far](https://github.com/barry-far/V2ray-Config)، [mhcfpTopic](https://github.com/mhcfpTopic/config)، [PSG](https://github.com/itsyebekhe/PSG) و [rzashakeri](https://github.com/rzashakeri/v2ray-configs)).
2. هر کانفیگ را با خود Xray تست می‌کند، با همان کدی که برنامه با آن وصل می‌شود ([`tools/ConfigTester`](tools/ConfigTester)): باید از داخل آن جواب گوگل بیاید و واقعاً دانلود کند.
3. مرده‌ها، خراب‌ها و تکراری‌ها را حذف می‌کند. تازه‌ها اول می‌آیند و سرورهای مختلف جلوتر پخش می‌شوند.

این تست بیرون از ایران انجام می‌شود، پس فقط سرورهای مرده را کنار می‌گذارد. اینکه کدام سرور روی اینترنت شما باز است را خود برنامه روی گوشی یا کامپیوتر شما می‌سنجد. خروجی سه فایل است:

| فایل | محتوا |
|---|---|
| [`derafsh_servers.txt`](derafsh_servers.txt) | لیست کانفیگ‌ها، جدیدترین‌ها اول |
| [`derafsh_sources.json`](derafsh_sources.json) | منبع هر کانفیگ (کانال تلگرام یا لیست گیت‌هاب) |
| [`derafsh_sub.txt`](derafsh_sub.txt) | همان لیست به شکل اشتراک استاندارد (base64) برای اپ‌های دیگر |

### نکته‌ی امنیتی

کانفیگ‌ها رایگان و از کانال‌های عمومی هستند و صاحب سرورها ناشناس‌اند. برای کارهای حساس (بانک، حساب‌های مهم) فقط از سایت‌های HTTPS استفاده کنید و رمزهای مهم را از طریق کانفیگ ناشناس وارد نکنید.

## English

**Derafsh** collects free V2Ray/Xray configs from public Telegram channels and public GitHub lists every 2 hours, and tests each one with Xray (through the app's own config builder, [`tools/ConfigTester`](tools/ConfigTester)) so dead ones never reach the list (GitHub Actions + [`collector.py`](collector.py)). The app (in Persian) connects with one button: it tests the configs on the network you're on (ping and download speed, remembering per network which servers worked) and picks the fastest one that answers, optionally only ones that open Gemini. While connected it keeps two tested spares and moves to one when the server drops or slows to a crawl, or when you press "switch server". Iranian sites (.ir, Iranian IPs) go direct, and on Android you choose which apps use the VPN (all except some, or only some); Iranian and banking apps are left out automatically. A second screen lists the servers (online, personal, and lists you save under your own names) for testing and choosing by hand — through the system proxy on Windows, as a VPN on Android.

- **Download:** [Releases](https://github.com/Mehinator/Derafsh/releases/latest) — `Windows-x64.zip` (unzip and run, Windows 10 1809+); Android 6+: `Android-arm64.apk` (most phones), `Android-armv7.apk` (32-bit phones) or `Android-universal.apk` (both).
- **Protocols:** VLESS (TCP, WebSocket, gRPC, XHTTP, HTTPUpgrade; TLS, REALITY), VMess, Shadowsocks, Trojan, Hysteria2 — on **Xray-core 26.10.22** (the patterniha fork). Configs the engine can't start, or that don't really download, are dropped by the collector.
- **Other apps:** the same list works as a subscription in v2rayNG, Hiddify or NekoBox: `https://cdn.jsdelivr.net/gh/Mehinator/Derafsh@main/derafsh_sub.txt`.
- **iPhone / iPad:** no iOS app yet; add the same subscription URL in Hiddify, V2Box or Streisand from the App Store, or scan [this QR code](docs/sub-qr.png).
- **Safety:** these are free servers run by unknown people. Prefer HTTPS sites and don't enter important passwords over them.

### Build from source

Requirements: Windows 10 1809+, the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) with the MAUI Windows workload (`dotnet workload install maui-windows`), or Visual Studio with the .NET MAUI workload.

```powershell
# run from source
dotnet build Derafsh.Client -c Debug
# self-contained release folder (what the release zip contains)
dotnet publish Derafsh.Client -f net10.0-windows10.0.19041.0 -p:TargetFrameworks=net10.0-windows10.0.19041.0 -c Release -r win-x64 --self-contained true `
  -p:WindowsPackageType=None -p:WindowsAppSDKSelfContained=true -p:PublishReadyToRun=true -o publish\Derafsh
# Android APK (needs the MAUI Android workload and a JDK); DerafshAndroidAbis = arm64 (default), armv7 or universal
dotnet build Derafsh.Client -f net10.0-android -c Release -p:DerafshAndroidAbis=arm64
```

The first build downloads Xray-core (and, for Android, hev-socks5-tunnel) from their official releases and checks their SHA-256.
Pushing a `v*` tag runs [`release.yml`](.github/workflows/release.yml), which builds both and attaches them to the release.

The config collector: `pip install requests` then `python collector.py`.

### Project layout

| Path | What it is |
|---|---|
| `Derafsh.Client/` | .NET MAUI app (`MainPage.xaml` UI, `Service/ConfigService.cs` link parsing and Xray config, `XrayProc.cs` engine process, `Resources/Styles/Theme.xaml` design tokens) |
| `Derafsh.Client/Platforms/Android/DerafshVpn.cs` | Android VPN: TUN → hev-socks5-tunnel → Xray SOCKS |

| `.github/workflows/release.yml` | release builds (Windows zip, signed APK) |
